《战线 1937–1945》v0.15.0 开发者编辑器更新

1. 移除“保存到源代码”和项目目录授权功能；正式修改统一通过导出 JSON 完成。
2. 保留开发者模式密钥门禁。
3. 新增“编辑地名”：点击地图格可新建、改名、改类型或删除地名。
4. 新增“编辑重要节点”：可在地图上新增节点、标记/取消 strategicObjective。
5. 新增“编辑战术目标”：点击目标位置后选择阵营，直接新建、修改或删除右侧战略/战术目标，右侧面板即时刷新。
6. 新增“编辑战术增援”：点击算子设置增援批次、到达回合、名称、说明、入口方向/坐标，并即时刷新增援面板。
7. 导出战役 JSON 包含：地名、重要节点、战术目标、地形、工事、城墙、城门。
8. 导出单位 JSON 包含：双方算子位置和战术增援字段。
