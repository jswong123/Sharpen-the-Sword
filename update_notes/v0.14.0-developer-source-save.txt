战线 1937–1945 v0.14.0

开发者模式安全与源文件保存更新：
1. 点击“开发者模式”必须输入密钥。
2. 开发者地图编辑器新增“保存到源代码”。
3. 首次保存必须由浏览器授权项目根目录；程序只写当前战役对应的 data/scenario-*.json 与 data/units-*.json。
4. 写入前要求目标文件已经存在，避免误选目录时创建错误源文件。
5. 每次源文件保存同时写入浏览器草稿，提供额外恢复点。
6. “保存浏览器草稿”仍只写 localStorage，不修改源文件。
7. GitHub Pages 页面可以在用户明确授权后修改本机项目目录，但不会自动 commit/push 到 GitHub 远程仓库。

安全说明：前端 JavaScript 中的固定密钥只能作为误触/普通访问门禁，无法防止能够查看网页源代码的人取得密钥。真正的远程仓库写权限仍应由 GitHub 身份认证控制。
