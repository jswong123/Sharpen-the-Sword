《战线 1937–1945》v0.20.0 Scenario Editor

1. 主界面新增密钥保护的开发者模式，可编辑战场、阶段、战役目录、战役隶属关系、名称、说明、日期、地点、数据路径、开放状态和模块宽高；支持新增/删除并导出 campaigns.json。
2. 战役开发者模式新增“添加/编辑正面战场单位”。点击空白格可直接创建第1回合部署单位，点击已有单位可编辑。
3. 单位类型使用默认模板。选择步兵、警卫、工兵、机枪、炮兵、反坦克、防空、侦察、骑兵、摩托化、装甲、坦克、司令部后自动填入兵力、攻击、防御、移动、射程、士气、弹药，之后所有数值均可手动微调。
4. 单位统一支持名称、阵营、出现回合、出现方向、攻击/防守/坚守/预备任务及目标。出现回合=1为正面战场，>1自动作为战术增援。
5. 增援出现方向扩展为八方向、自动、指定点、港口、租界。
6. 作战目标候选读取战术目标与地图地名/重要节点。
7. 保留地形、工事、城墙、城门、地名、重要节点、战术目标编辑及 JSON 导出。
8. 不直接修改项目源代码；正式更新使用导出的 JSON 替换 data 文件。
